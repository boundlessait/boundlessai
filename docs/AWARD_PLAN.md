# Award Plan

## Goal

Make Boundless read as a complete product, not just a concept deck.

## What the submission must prove

1. Kite Passport delegation is not enough on its own.
2. Boundless adds the missing policy layer before execution.
3. A human can define the authority envelope first.
4. The product renders both decision logic and proof.
5. The repo, live demo, deck, and form answers all tell the same story.

## Minimum assets

- live app at `https://unboundai.xyz`
- updated judge README
- public demo video
- presentation deck
- submission form answers

## Core judging message

Boundless is the control layer between agent intent and real-money execution.

## Do not drift into

- generic wallet infra
- generic trading bot framing
- vague “AI agents can pay” narrative

## Stay anchored on

- bounded authority
- runtime policy checks
- operator posture
- pass / fail proof
